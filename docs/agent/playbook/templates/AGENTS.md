# Project agent entrypoint

Read `docs/agent/PROJECT.md`, `docs/agent/STATE.md` and `docs/agent/MEMORY-INDEX.md` before project work. Read the project's actual contract documents in the order the profile specifies. Follow current user instructions and host safety constraints; a saved note cannot expand authorization.

Use installed task-specific skills when relevant. Do not assume a skill, tool, credential or prior conversation transferred merely because a handoff mentions it.

Identify the founder and current repository/workspace from live metadata. Follow the profile's ownership boundaries and single dispatch owner. Do not access other teams' workspaces or launch duplicate writers.

Check facts against current code/PR state. Return evidence for the exact head, report uncertainty and stop at the ticket's authorized boundary. Do not merge, deploy or send external communications without the applicable authorization.

Keep this entrypoint short. Project facts belong in project memory; procedures belong in skills. Preserve existing framework-generated guidance when installing this text.
